    简历条目与 5 分钟 PPT 素材¶

    简历写法（项目栏 3-4 行）¶

    数字通信物理层全链路仿真与深度学习调制识别（Python/NumPy/PyTorch， 独立项目，GitHub + 文档站）

    • 从零实现单载波突发收发机：卷积码 + 软判决 Viterbi、RRC 成型、ZC 前导 定时、Moose CFO 估计、LS 信道估计 + MMSE 均衡、判决引导相位跟踪， 瑞利多径 + CFO 下端到端 BER 验证；
    • 实现 64 载波 OFDM 收发机：S&C 定时、导频辅助信道估计与 CPE 跟踪， 与单载波方案在同信道下对比验证；
    • 用仿真链路作数据工厂训练 1D-ResNet 调制分类器（5 类，Kaggle GPU 全量 训练混合 SNR 准确率 ~77%，混淆结构符合理论预期）；
    • 57 项数值测试与理论曲线/理论界对齐，逐模块中文讲解文档 + CI 自动验证。

    简历上一定要附 GitHub 链接和文档站链接——让面试官能点进去看到代码 和图，可信度翻倍。

    5 分钟 PPT 大纲（复试陈述用）¶

    现成文件：docs/interview/phy-layer-sim-amc-复试陈述.pptx——8 页 16:9 成品（P1–P7 + 一页备用数字速查），已嵌入仓库实验图。 重新生成：pip install python-pptx && python3 tools/build_ppt.py。 改内容请同步改本页口播稿与速查卡，数字以 verification.md 为准。

    按 7 页安排，每页 ~40 秒：

    P1 封面：题目《基于 Python 的数字通信物理层仿真与智能调制识别》+ 姓名 + 一句话定位："把通信原理整本书变成一条能跑的链路，再加一个 AI 模块"。

    P2 动机与架构图：为什么做——通信原理公式学了一堆但没见过它们连起 来的样子。放 docs/index.md 里的链路框图（两条链路 + AMC 旁路）。

    P3 关键技术亮点（选两个讲透，不要罗列）： - 突发接收机流水线：一张接收流程箭头图 + "我调通的四个真实坑"一句话 带过（周期模糊/伪相关峰/噪声泄漏/首径检测）——这条是整场最加分的： 说明你懂工程不是抄代码； - OFDM：S&C 定时平台图 + 信道估计 \(|\hat H(f)|\) vs 真实对比图 （assets/ofdm_internals.png）。

    P4 验证结果：三张图——exp02 的 BER vs 理论曲线（证明仿真正确）、 exp03 编码增益曲线（编码 vs 不编码）、exp04 单载波 vs OFDM 对比。 每张图一句话结论。

    P5 AMC 模块：数据集生成流程一行 + 混淆矩阵图 + "网络自己学出了 PSK 族/QAM 族的混淆结构，和教科书结论一致"。

    P6 工程素养：57 项测试、MkDocs 文档站、CI、可复现实验脚本——10 秒带过，展示的是习惯。埋伏一个深挖点：估计器全部对照理论界验证 （CFO 方差达渐近界、LS 逐抽头 MSE=σ²/Ntr、ICI 闭式匹配仿真）—— 老师追问"怎么证明你的估计器是对的"时直接接招。

    P7 总结与展望：一句话总结 + 展望三条（LDPC/Polar 编码、RML2016 对照、SDR 实物验证）。最后一句扣回报考方向。

    逐页口播稿（练到背下来）¶

    每页 ~40 秒、3~4 句以内。粗体数字是已验证过的，敢说。括号里是埋伏点—— 故意留的钩子，老师顺着问就用问答手册接。

    P1（20 秒）："各位老师好，我的项目是把通信原理里一条完整链路从比特到 比特实现出来——信道编码、调制、成型、同步、均衡、OFDM，再让这条链路自己 产数据，训练神经网络识别调制方式。物理层链路全部用 NumPy 手写（AMC 用 PyTorch），没有调通信库。"

    P2（30 秒）："动机很简单：课上学了一堆公式，但没见过它们连成一条链路 的样子。这张图是架构——左边发射、右边接收，接收端每一级对应撤销一种 信道损伤。我按'一级一个问题'组织代码，所以每个模块都能单独讲透。" （钩子：老师若问"为什么这么分模块"，答：每个框对应课本一章）

    P3（60 秒，全场最重）："难点都在接收端。我挑两个讲。第一，突发接收机 流水线：先相关定帧，再两段 ZC 前导做 Moose 载波频偏估计，LS 信道估计， MMSE 均衡，判决引导相位跟踪。调通它的过程里我遇到过伪相关峰、周期模糊、 噪声泄漏、首径选错四个真实的坑。"（钩子：四个坑每个都能展开成故障→定位 →解法的小故事；再深一步就说"估计器我对照理论界验证过——CFO 估计方差 3.5e-5 周/样点，离渐近界只差 2%，LS 每抽头误差 σ²/Ntr"）

    P4（60 秒）："这是验证结果。左边 BER 对理论曲线逐点压线，说明仿真 没写错；中间编码增益曲线能看出软判决 Viterbi 的工作区增益约 2dB； 右边 OFDM 和单载波同信道对比——低 SNR 下 OFDM 反而更好，因为有限长 MMSE 均衡器退化后残留 ISI 除不掉，而 OFDM 把 ISI 化成了逐载波平坦衰落； 高 SNR 时 OFDM 有 ~1% 残留误码，来自深衰落载波的噪声放大——这正是 OFDM 必须配交织编码的原因。"（钩子：若问 CFO 不补偿会怎样，直接抛 ICI 闭式： ε=0.192 时 −9.4dB，QPSK 都有地板；补偿后残余 −48dB）

    P5（40 秒）："最后用前面这条链路当数据工厂，喂给 1D-ResNet 做调制 识别。Kaggle GPU 全量训练混合 SNR 准确率 76.9%、高 SNR 端 ~88%。 最有意思的是混淆矩阵的结构：网络自己学出了 PSK 族内、QAM 族内的混淆对， 和人类用手工统计特征得到的教科书结论一致——说明它学到的是物理特征。"

    P6（10 秒）："工程习惯上：57 项数值测试、逐模块中文文档站、CI、 可复现实验脚本，还有一页'每条数字怎么复核'的清单——文档里每个数字都能 用一条命令重算出来。"

    P7（20 秒）："总结：项目把课本理论落成了一条可验证链路，外加一个 AI 识别模块。下一步可以做 LDPC/Polar、在 RadioML 公开数据集上对照、 或上 SDR 实物验证。我对物理层链路这个方向很感兴趣，希望在研究生阶段 继续深入。"
