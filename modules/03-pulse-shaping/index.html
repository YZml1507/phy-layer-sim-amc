    03 脉冲成型与匹配滤波¶

    代码：src/phylayer/pulse_shaping.py 验证：tests/test_pulse_shaping.py

    它解决什么问题¶

    符号序列要变成连续时间波形才能发射。最朴素的选法是矩形脉冲——一个符号 电平持续一个符号周期 \(T_s\)。但矩形脉冲的频谱是 sinc 函数：

    \[ \mathrm{rect}(t/T_s)\ \longleftrightarrow\ T_s\,\mathrm{sinc}(fT_s) \]

    sinc 的旁瓣以 \(1/f\) 衰减、带宽无穷大——意味着发射机往邻道疯狂漏能量， 这是任何实际系统都不能容忍的（频谱是管制资源）。

    所以必须换带限脉冲 \(p(t)\)。但带限和"时间上干净"是矛盾的：频谱切得越 干净，时域拖尾越长（傅里叶对偶：频域突变 ⟺ 时域长拖尾）。拖尾会砸进相邻 符号的判决时刻——这就是码间串扰 ISI。成型滤波要同时满足两个互相拉扯 的目标：带得够窄，采样瞬间邻居贡献为零。

    原理¶

    奈奎斯特无 ISI 准则¶

    发端成型 \(p_{tx}(t)\)、信道 \(c(t)\)、收端滤波 \(p_{rx}(t)\) 级联的总响应记

    \[ g(t) = p_{tx}(t) * c(t) * p_{rx}(t) \]

    在理想 AWGN 信道（\(c(t)=\delta(t)\)）下 \(g = p_{tx}*p_{rx}\)。第 \(k\) 个符号的 采样值是

    \[ y[k]=\sum_n a_n\,g(kT_s-nT_s)+n[k]=a_k g(0)+\sum_{n\neq k}a_n g\big((k-n)T_s\big)+n[k] \]

    要第二项（邻居泄漏）恒为零，充要条件是

    \[ g(kT_s)=\begin{cases} 1 & k=0 \\ 0 & k\neq 0 \end{cases} \]

    频域等价表述（奈奎斯特准则）：\(g(t)\) 的频谱按符号率折叠后必须为常数：

    \[ \sum_{m} G\!\left(f-\frac{m}{T_s}\right) = T_s\quad(\text{常数}) \]

    这条等价不是巧合：由泊松求和，折叠谱 \(\sum_m G(f-m/T_s)=T_s\sum_k g(kT_s)e^{-j2\pi fkT_s}\) 正是采样序列 \(\{g(kT_s)\}\) 的 DTFT——\(g(kT_s)=\delta[k]\) 的 DTFT 是常数 \(T_s\)， 反之亦然，两表述严格互充。满足这条的最小带宽是 \(1/(2T_s)\)（奈奎斯特带宽），此时脉冲是 sinc——带宽最优但拖尾按 \(1/t\) 衰减， 对定时误差极度敏感，不可实用。

    升余弦（RC）谱是最常用的满足条件的实用波形：频谱在 \(\pm 1/(2T_s)\) 处关于该点奇对称地余弦滚降，占用带宽 \((1+\beta)/(2T_s)\)，\(\beta\in[0,1]\) 是滚降因子。β=0 退化为 sinc， β=1 带宽翻倍但拖尾衰减极快。

    为什么收发各用一个"根"升余弦¶

    设计约束有两条，而且要同时成立：

    1. 级联总响应是 RC（满足无 ISI）：\(|P_{tx}(f)|\cdot|P_{rx}(f)|=RC(f)\)；
    2. 接收端要匹配滤波：\(p_{rx}(t)=p_{tx}^*(-t)\)（下节说明为什么）。

    把 (2) 代入 (1) 得 \(|P_{tx}(f)|^2=RC(f)\)，即收发两边都用

    \[ |P_{tx}(f)|=|P_{rx}(f)|=\sqrt{RC(f)} \]

    这就是根升余弦 RRC。发射 RRC → 信道 → 接收 RRC，级联 \(|RRC|^2=RC\) 恰好无 ISI，同时接收端实现了匹配滤波、输出信噪比最优。"根号"就是这么来的； WCDMA、DVB-S2 等标准把 RRC 直接写进了规范；5G NR 不规定发送成形，工程上多用加窗或 RRC 类滤波实现。

    匹配滤波为什么最优（柯西-施瓦茨一句话证明）¶

    在白噪声下，对采样时刻输出信噪比做优化：信号项是卷积 \(y_s(0)=\int h(\tau)s(-\tau)d\tau\)， 噪声项功率是 \(\sigma^2\int|h|^2\)。由柯西-施瓦茨不等式

    \[ \left|\int h\,s^* \right|^2 \le \int|h|^2 \cdot \int|s|^2 \]

    等号当且仅当 \(h(t)\propto s^*(-t)\) 时取得——即滤波器是发送脉冲的 时间反转共轭。物理图像：脉冲能量集中在哪，匹配滤波就在哪"加权收集"， 信噪比最大化。定量结论：复基带口径下匹配滤波器输出的符号信噪比恰为 \(E_s/N_0\)（带通口径写作 \(2E_s/N_0\)，差在噪声维度定义）——所以本项目 仿真的"\(E_s/N_0\)"就是判决点 SNR，实测 BER 才能直接对理论线。

    滚降因子 β 的工程权衡¶

    • β 大（如 0.5+）：占带宽多，但拖尾衰减快 → 对定时偏差鲁棒；
    • β 小（如 0.1）：几乎贴着奈奎斯特带宽，但拖尾接近 sinc 的长尾巴 → 定时采样偏一点，邻居符号就漏进来。

    工程常用 0.2–0.35（DVB-S2 用 0.35/0.25/0.2；WCDMA 用 0.22）。项目默认 β=0.35、span=11 个符号、sps=8 倍过采样。

    另外两个实现细节¶

    1. 群延迟：FIR 滤波器长度 span·sps（本项目 11×8=88 抽头），卷积使输出整体延后 (len(h)-1)/2 个样点（对称 FIR 的群延迟）；级联两个 RRC 共延后 len(h)-1，所以接收端要 y[len(h)-1 :: sps] 才对齐到符号中心。
    2. SNR 换算：波形按 sps 过采样后，每个采样点平均分到 \(E_s/\mathrm{sps}\) 的能量；对波形级加噪时目标 SNR 要减 \(10\log_{10}(\mathrm{sps})\) （channels.snr_for_waveform 封装了这一步，模块 01 的约定里讲过原因）。

    代码走读（按调用顺序）¶

    h = rrc_taps(beta=0.35, span=11, sps=8)   # RRC 抽头, 单位能量
x, h = tx_rrc(symbols, beta, span, sps)   # 上采样(补零) + RRC 卷积
y = rx_rrc(channel_output, h)             # 接收端匹配滤波（同一个 h）
z = y[len(h)-1 :: sps]                    # 补偿群延迟后按符号率抽取

    验证结果¶

    test_rrc_cascade_is_nyquist：收发级联采样值与原始符号的均方误差 < 1e-4 ——数值上证明 ISI 为零。test_shaped_ber_matches_theory：整条 "调制→成型→AWGN→匹配滤波→判决"链的 BER 仍落在理论曲线上。

    面试可能怎么问¶

    • 为什么不用矩形脉冲？ 频谱是 sinc、带外辐射大；真实信道带宽受限， 必须带限成型。
    • 升余弦为什么无 ISI？ 频谱关于 \(\pm 1/(2T_s)\) 奇对称滚降 ⟹ 折叠谱 为常数（奈奎斯特准则）⟺ 时域在 \(kT_s\) 处过零。
    • 为什么收、发各用一个根号？ 总响应要 RC（无 ISI）+ 接收要匹配滤波 （最大化 SNR），两个约束的联立解就是 RRC/RRC。
    • β 取大取小各有什么好处？ 见上文权衡；追问"为什么 β 小对定时敏感"—— 拖尾衰减慢（接近 sinc 的 \(1/t\)），采样点一偏邻居能量就漏进来。
    • 匹配滤波为什么最优？ 白噪声下最大化采样点 SNR；柯西-施瓦茨可证 最优解 \(h_{opt}(t)=s^*(-t)\)。
    • 眼图是什么？ 把波形按 1–2 个符号周期切片叠画；眼睛张开度同时反映 定时余量、噪声余量和 ISI 大小。ISI 会让"眼皮"变厚、眼高变窄。
    • 奈奎斯特带宽是多少？ 符号率 \(R_s=1/T_s\) 的基带信号最小无 ISI 带宽 是 \(R_s/2\)（升余弦取 \((1+\beta)R_s/2\)——这是基带单边口径；实通带信号 双边占用 \((1+\beta)R_s\)）。按通带口径算频谱效率 \(\eta=\log_2 M/(1+\beta)\)： QPSK+RRC(β=0.35) 约 \(2/1.35\approx1.48\) bit/s/Hz。
