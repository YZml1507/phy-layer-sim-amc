    09 信道估计¶

    代码：单载波 sync.py::estimate_channel_ls，OFDM ofdm.py::ofdm_rx 一句话：用一段收发双方都已知的序列，把信道 \(h\)（或 \(H\)）"测"出来， 交给均衡器/检测器去抵消。

    它解决什么问题¶

    均衡（模块 07）要知道信道 \(h\) 才能设计逆滤波器 \(w\)；OFDM（模块 08） 要知道 \(H_k\) 才能逐载波除法。但接收机不是先知——信道是发射时"顺带" 加上去的损伤，必须测量。办法就是：发一段双方都知道的参考信号 （训练序列/前导/导频），把"已知输入、观测输出"变成解方程。

    原理¶

    时域 LS（单载波突发用）¶

    训练段接收信号满足线性模型 \(y = Xh + n\)，\(X\) 是训练序列排成的 Toeplitz 卷积矩阵。最小二乘解：

    \[ \hat h=(X^H X)^{-1}X^H y \]

    物理图像：\(h\) 有 \(L\) 个未知抽头，训练段有 \(N_{tr}\) 个观测——\(N_{tr}=L\) 时方程恰定、\(N_{tr}>L\) 时超定，噪声被最小二乘"平均"掉一部分。实现用 np.linalg.lstsq。

    能估多准——误差方差有闭式：LS 估计误差 \(\mathrm{cov}(\hat h-h)=\sigma^2(X^H X)^{-1}\)，即每抽头 \(\mathrm{var}(\hat h_j)=\sigma^2[(X^H X)^{-1}]_{jj}\)。用 CAZAC 类理想 自相关序列时 \(X^H X\approx N_{tr}E_s\,I\)，于是每抽头均方误差

    \[ E|\hat h_j-h_j|^2\approx\frac{\sigma^2}{N_{tr}} \]

    （单位能量符号 \(E_s=1\)；蒙特卡洛实测均值比值 ~1.0–1.05——边界抽头受 Toeplitz 截断影响略差，\(L=12\) 时最差抽头约 1.13）。三个直接推论： 训练长度翻倍，抽头方差减半； 总 MSE \(=L\sigma^2/N_{tr}\) 与未知量个数成正比——这是"为什么要截短 信道"的定量理由；条件数差的训练序列让 \((X^H X)^{-1}\) 对角线鼓起来， 估计直接被噪声灌爆。

    顺带的副产品——噪声方差估计：拟合残差里只剩噪声，

    \[ \hat\sigma^2=\mathrm{var}(y-X\hat h) \]

    这个 \(\hat\sigma^2\) 正好是 MMSE 均衡器的正则化参数——估信道和估噪声 用同一段训练序列一次完成。

    本项目踩过的坑：残差必须在整段训练序列上算。最初只在 64 符号长前导 上算残差，短前导尾部能量泄漏进了信号段——残差不再纯净是噪声， \(\hat\sigma^2\) 被高估 10 倍，MMSE 退化成"不敢动手"的懒均衡器。

    频域 LS（OFDM 用）¶

    OFDM 训练符号每个载波 \(X_k\) 已知：\(\hat H_k = Y_k/X_k\)——62 个可用载波 各自一次除法代替解方程组，便宜得多；代价是每个载波独立估计、噪声不被平滑。

    降噪：IFFT-截断-FFT¶

    频域 LS 噪声大的解药：\(\hat H\) 做 IFFT 得时域冲激响应估计 \(\hat h[n]\)， 利用"信道物理拖尾 ≤ CP 长"这个先验，把 \(n\ge N_{cp}\) 的抽头清零再 FFT 回来。

    为什么有效：IFFT 把每个载波上的 LS 噪声均匀摊到全部 \(N\) 个时域 抽头上，截断直接扔掉 \(N-N_{cp}\) 份噪声能量——于是重构回频域后每个 载波的估计噪声方差乘 \(N_{cp}/N\)（64→16 ≈ 降 6 dB），总估计 MSE 同 比例下降。本质上是降秩估计：把频域估计投影到"时域长度 \(\le N_{cp}\)"的 \(N_{cp}\) 维子空间，和 LMMSE 用先验协方差 \(R_h\) 收缩是 同一个思想——只是把先验简化成"CP 外为零"。前提：真实信道确实比 CP 短，否则砍掉真抽头引入模型误差。

    导频：初始估计 + 持续跟踪¶

    一次训练只能给快照——信道估计是个快照，但 CFO 残差、相位噪声、定时 抖动会让"真信道"随时间漂移。工程架构是初始估计 + 持续跟踪：数据 符号里塞导频载波，每个符号重估一次公共相位误差（CPE），跟踪慢漂移。 802.11 的 4 导频、LTE 的 CRS、5G 的 DM-RS/PT-RS 全是这个架构。

    代码走读（按调用顺序）¶

    # 单载波突发（模块 06 流水线里的一步）
h_hat = estimate_channel_ls(pre_rx, pre_tx_full, n_taps)  # 只返回 h
noise_var = mean(|pre_rx - conv(pre_tx_full, h_hat)[:N_tr]|^2)  # 残差估噪声

# OFDM（模块 08 流水线里的一步）
H_ls = Y_tr / X_tr                      # 逐载波 LS
h_td = np.fft.ifft(H_ls); h_td[cp:] = 0 # 时域截断
H_hat = np.fft.fft(h_td)                # 回频域

    面试可能怎么问¶

    Q：LS 和 MMSE 信道估计的区别？ A：LS 只用已知序列解线性方程，不用信道统计先验，简单但噪声大；MMSE 用信道二阶统计 \(R_h\) 和噪声方差做维纳滤波 \(\hat h_{MMSE}=R_hX^H(XR_hX^H+\sigma^2I)^{-1}y\)，性能更好但要知道信道 先验（工程上不一定拿得到）。折中：LS + 时域截断/频域平滑——本项目 OFDM 用的就是这个，等价于利用时域稀疏先验的降秩/DFT 域估计。

    Q：信道估计的噪声方差怎么顺手估计？ A：训练段拟合残差 \(\mathrm{var}(y-X\hat h)\)。副产品很实用：MMSE 均衡 器、LLR 软解调都要它。

    Q：训练序列有什么讲究？ A：自相关好（旁瓣低）→ \(X^H X\) 条件数小、LS 稳定；恒模（CAZAC，如 ZC）→ 发射端 PAPR 友好。本项目单载波用 Zadoff–Chu，OFDM 训练符号 用全载波 BPSK PN。

    Q：为什么训练序列要"已知"？能不能盲估计？ A：已知才能把"测量信道"变成解方程。盲信道估计（二阶统计、恒模特性） 存在但慢且不可靠——所有现代突发包系统都用已知前导/导频，是行业标准 做法。

    Q：信道估计误差会怎样传导？ A：估计误差等效于均衡器/除法器拿错 \(H\)——剩下的信道和噪声没区别， 星座散开、BER 抬高。所以信道估计是链路预算的一部分，不是"免费"的。
