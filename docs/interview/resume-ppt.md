# 简历条目与 5 分钟 PPT 素材

## 简历写法（项目栏 3-4 行）

**数字通信物理层全链路仿真与深度学习调制识别**（Python/NumPy/PyTorch，
独立项目，GitHub + 文档站）

- 从零实现单载波突发收发机：卷积码 + 软判决 Viterbi、RRC 成型、ZC 前导
  定时、Moose CFO 估计、LS 信道估计 + MMSE 均衡、判决引导相位跟踪，
  瑞利多径 + CFO 下端到端 BER 验证；
- 实现 64 载波 OFDM 收发机：S&C 定时、导频辅助信道估计与 CPE 跟踪，
  与单载波方案在同信道下对比验证；
- 用仿真链路作数据工厂训练 1D-ResNet 调制分类器（5 类，Kaggle GPU 全量
  训练混合 SNR 准确率 ~77%，混淆结构符合理论预期）；
- 57 项数值测试与理论曲线/理论界对齐，逐模块中文讲解文档 + CI 自动验证。

> 简历上一定要附 GitHub 链接和文档站链接——让面试官能点进去看到代码
> 和图，可信度翻倍。

## 5 分钟 PPT 大纲（复试陈述用）

按 7 页安排，每页 ~40 秒：

**P1 封面**：题目《基于 Python 的数字通信物理层仿真与智能调制识别》+
姓名 + 一句话定位："把通信原理整本书变成一条能跑的链路，再加一个
AI 模块"。

**P2 动机与架构图**：为什么做——通信原理公式学了一堆但没见过它们连起
来的样子。放 `docs/index.md` 里的链路框图（两条链路 + AMC 旁路）。

**P3 关键技术亮点**（选两个讲透，不要罗列）：
- 突发接收机流水线：一张接收流程箭头图 + "我调通的四个真实坑"一句话
  带过（周期模糊/伪相关峰/噪声泄漏/首径检测）——这条是整场最加分的：
  说明你懂工程不是抄代码；
- OFDM：S&C 定时平台图 + 信道估计 $|\hat H(f)|$ vs 真实对比图
  （`assets/ofdm_internals.png`）。

**P4 验证结果**：三张图——exp02 的 BER vs 理论曲线（证明仿真正确）、
exp03 编码增益曲线（编码 vs 不编码）、exp04 单载波 vs OFDM 对比。
每张图一句话结论。

**P5 AMC 模块**：数据集生成流程一行 + 混淆矩阵图 + "网络自己学出了
PSK 族/QAM 族的混淆结构，和教科书结论一致"。

**P6 工程素养**：57 项测试、MkDocs 文档站、CI、可复现实验脚本——10
秒带过，展示的是习惯。埋伏一个深挖点：估计器全部对照理论界验证
（CFO 方差达渐近界、LS 逐抽头 MSE=σ²/Ntr、ICI 闭式匹配仿真）——
老师追问"怎么证明你的估计器是对的"时直接接招。

**P7 总结与展望**：一句话总结 + 展望三条（LDPC/Polar 编码、RML2016
对照、SDR 实物验证）。最后一句扣回报考方向。

为什么难、验证了什么"。把 P3-P4 练到 90 秒之内，整场就稳了。
