# 面试追问预判与应答手册

> 用法：每题先自己口述答案，再对照。所有"A"都按"一句话结论 → 展开 →
> 扣回项目"组织——面试官记住的是结构，不是细节。
> 各模块详细推导见 `modules/` 下对应页面；本页只收高频追问。

## 一、项目总览类（开场必考）

**Q：介绍一下你的项目。**
A（30 秒版）："我用 Python 从零实现了一条数字通信物理层仿真链路：单载
波突发收发机（卷积码+同步+均衡）和 OFDM 收发机两条链路都跑通了端到端
误码率验证，然后把这个链路反过来当数据工厂，训练了一个 1D-ResNet 做
自动调制识别。所有模块都有和理论对齐的数值测试。"

**Q：为什么不用 MATLAB / 不调现成的 comm 库？**
A：三个原因：① 我要的是理解不是结果——自己写卷积矩阵、自己推 MMSE
解，踩过的坑才是真理解；② Python+NumPy 是 ML 生态，AMC 模块直接复用
同一套链路；③ 全程可复现（CI 测试+文档站），面试官可以当场验证。

**Q：项目里最难的地方？**
A：同步。BER 曲线蒙对容易，真正的坑都在对齐上——我踩过四个：两段重复
前导的周期模糊、部分重叠伪相关峰、噪声方差被前导泄漏高估、OFDM FFT
窗口方向不对称。（每个展开见对应模块页，挑一个展开讲。）

## 二、按模块高频追问

### 调制/成型（对应模块 02、03）

**Q：为什么用 Gray 映射？**
A：相邻星座点只差 1 bit——高 SNR 下误符号几乎都是跳到邻居，Gray 让符
号错只带 1 个 bit 错，BER 最小化。

**Q：RRC 为什么用一对而不是一个 RC？**
A：频域上 RC 在收发各开一半根号 → 合成 RC 满足无 ISI 条件，同时接收
端那个 RRC 恰好是匹配滤波器（最大化 SNR）。滚降系数 β 是带宽-vs-拖尾
的权衡。

**Q：星座图每个点为什么能量归一？**
A：比较不同调制的 BER 要在同一 $E_s/N_0$ 下才有意义，不归一就是拿
64QAM 的大能量作弊。

### 编码（模块 04）

**Q：软判决比硬判决好多少？**
A：理论 ~2dB 编码增益（AWGN 下）。本质是信息量：硬判决把幅度扔了只留
符号位，软判决保留"多不确定"。本项目实测 14dB 起编码 QPSK 零误码而
不编码还差两个量级。

**Q：交织器干嘛的？**
A：把信道上的连续错误（衰落深坑、突发干扰）打散成随机孤立错——卷积
码擅长纠随机错，怕突发。5G/WiFi 里编码+交织永远成对出现。

### 同步（模块 06）

**Q：定时同步怎么做？**
A：两步：相关定帧（前导匹配滤波找大概位置），精同步在 ±margin 窗口里
对抽取相位扫描。坑：多径下相关峰是一簇不是一根，要回扫找**首径**，
否则均衡器要多吃掉不必要的延迟。

**Q：CFO 怎么估？**
A：Moose/两半天估计——前导里放两段相同内容，相隔 L 的两段相关相位差
$2\pi\epsilon L$。注意估计范围和精度的矛盾：L 大精度高但可测频偏范
围小（$|\epsilon|<1/(2L)$）。

**Q：频偏为什么不能忽略？**
A：$e^{j2\pi\epsilon n}$ 随采样点累积——帧尾相位能转好几圈，星座图
整个旋转。短帧可以先纠 CFO 再靠判决引导相位跟踪残余。

### 均衡（模块 07）

**Q：ZF 和 MMSE 区别？**
A：ZF 把 ISI 完全置零但信道有深零点时噪声被放大；MMSE 加噪声正则项
$(H^HH+\sigma^2I)^{-1}H^He_d$，在残余 ISI 和噪声放大之间折中，
$\sigma^2\to0$ 退化成 ZF。实测里 MMSE 的均衡延迟要全扫一遍——非最小
相位信道上固定延迟会留大量残余 ISI。

**Q：信道估计怎么做的？**
A：训练序列排成 Toeplitz 矩阵解 LS；残差顺手估计噪声方差喂给 MMSE。
坑：残差要在整段训练上算，只在部分上算会把相邻信号的能量泄进噪声估
计（我被这个坑过——噪声高估 10 倍，均衡器直接变懒）。

### OFDM（模块 08、09）

**Q：CP 的作用和代价？**
A：把线性卷积变循环卷积 → DFT 对角化信道 → 每载波除一个复数；代价
$N_{cp}/(N+N_{cp})$ 带宽。CP 必须 ≥ 信道拖尾。

**Q：FFT 窗位置有什么讲究？**（本项目最出彩的坑）
A：偏早合法但有上界（偏早量 $\le N_{cp}-(L-1)$，窗内装下信道拖尾时
循环移位才被 $H$ 吸收成线性相位），偏晚灾难（窗口末端抓到下一符号的
CP 样本）。所以接收机宁可偏早——我显式偏 2 个采样。

**Q：OFDM 相比单载波的优势/劣势？**
A：优：均衡 O(1)/载波、对长拖尾信道友好、频谱利用灵活。劣：PAPR 高、
对 CFO/相噪敏感、深衰落载波上 ZF 噪声放大（要编码交织兜底——所以我
们链路里卷积码不是可选配件）。

### AMC（模块 10）

**Q：AMC 是什么？为什么用深度学习？**
A：不看帧结构直接对原始 IQ 判断调制方式。传统方法是手工特征+决策树
（高阶累积量、循环谱）；深度学习让网络从数据里学特征，RML2016.10a 上
CNN 类模型公开结果约 85%+ 高 SNR 准确率（口径因论文略有差异）。

**Q：混淆矩阵说明了什么？**
A：QPSK↔8PSK 混（恒模近亲）、16QAM↔64QAM 混（方形 QAM 近亲）——
和人工特征方法的已知结论一致，说明网络学的是物理结构。

**Q：仿真训练能用到真实信号吗？**
A：有 gap（仿真缺相位噪声/IQ 不平衡/功放非线性），用域随机化和真实数
据微调缓解——能说出这个边界本身就加分。
