## 三、必背实测数字

- **CFO 估计**：std 3.5e-5 cyc/sample ≈ 0.10°/sym，实测/理论界 = 1.02（达界）
- **ICI 两档**：不补偿（ε=0.192）→ −9.4dB，QPSK 地板 ~3e-3、16QAM ~26%、64QAM ~70% 报废；Moose 补偿后残余 ε≈2e-3 → −48dB 可忽略
- **均衡代价**：severe 多径 Δ≈+13~21dB（demo 实测），MMSE 均衡后 SER 27.4%→0.024%
- **Ricean K**：深衰落概率 K=0→9.5%、K=3→2.8%、K=10→0.1%
- **AMCNet(5 类)**：参数量 332,165（≈33 万）
- **测试**：57 项 Python + 6 项 JS 回归

## 四、高危易错点（答错=掉分重灾区）

1. **Es/N0 vs Eb/N0**：差 10log₁₀k，说"信噪比"前先声明口径
2. **σ_τ 单位**：本项目抽头按**样点**间隔（不是符号周期），severe 2.01 样点
3. **ICI 锚定值**：OFDM 实验注入 CFO=3e-3 cyc/sample→ε=0.192，**不是**突发链路的 8e-4
4. **0 误码 ≠ BER=0**：只能报上界 <1/(N·k)
5. **ZF 在低 SNR/深衰落下比 MMSE 差**但高 SNR 趋同；瑞利信道 ZF 理论上噪声增强无界
6. **OFDM 低 SNR 反而优于单载波**：有限长 MMSE 均衡器在低 SNR 退化为匹配滤波，残留 ISI 不除
7. **Gray ≠ 必须**：自然二进制也能解调，只是 BER 虚高——演示页里就是这个差别
