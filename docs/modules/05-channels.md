# 05 信道模型

> 代码：`src/phylayer/channels.py`
> 用于：所有实验的信道仿真（AWGN / 多径 / CFO / 相位噪声 / 采样偏差）

## 它解决什么问题

真实无线信道不是简单的"加噪声"：电磁波经多条路径到达（多径）、收发双方晶振
不对齐（载波频偏 CFO）、采样钟有偏差、还有相位噪声。**接收机的全部复杂性
都来自信道损伤**——模块 06/07 的同步和均衡就是为了对抗它们。

## 原理与本项目的建模

### AWGN

复基带加性高斯白噪声：$y = x + n$，$n \sim \mathcal{CN}(0, \sigma^2)$，
$\sigma^2 = E_s / 10^{\mathrm{SNR}/10}$。

约定：本项目的 `snr_db` 一律指**符号级** $E_s/N_0$（符号能量归一）。波形级
仿真时每个符号被扩成 `sps` 个采样点，噪声功率按每采样点计——
`snr_for_waveform` 做换算：$\mathrm{SNR}_{wave} = E_s/N_0 - 10\log_{10}(sps)$。

### 多径衰落（TDL 模型）

离散抽头延迟线：$y[k] = \sum_j h_j\, x[k - j\cdot sps]$（符号间隔抽头）。
`rayleigh_taps` 生成指数衰减、总功率归一的瑞利抽头：

$$h_j \sim \mathcal{CN}(0, 10^{-j\cdot d/10}),\qquad \sum_j |h_j|^2 = 1$$

每根抽头独立复高斯 → 每径幅度瑞利分布 → 频率选择性衰落（频域响应起伏）。

- `multipath`：样点间隔抽头（亚符号延迟，与成型滤波器卷积后会引起符号间
  干扰 ISI 的精细结构）
- `multipath_symbol`：符号间隔抽头（TDL 抽头打在符号栅格上，等价于
  "符号率看到的等效信道"）

### 莱斯信道

`rician_taps`：视距径（LOS，确定性强径）+ 瑞利散射径，$K$ 因子控制强弱比。

### 载波频偏（CFO）

收发晶振差 $\Delta f$ 让星座持续旋转：$y[k] = x[k]\,e^{j2\pi\Delta f k}$。
`carrier_offset(x, cfo_norm)` 中 `cfo_norm` 单位是 cycles/sample（归一化）。
本项目突发链路取 $8\times10^{-4}$（8 sps 下每符号转 $0.64°$——整帧几百个
符号累计起来足够把 16QAM 星座转糊）。

### 相位噪声 / 采样偏差

`phase_noise`：Wiener 相位过程（随机游走相位），模拟本振相位抖动。
`sample_delay`：分数延迟滤波（理想插值），模拟采样钟偏差。

## 代码走读

```python
taps = rayleigh_taps(n_taps=5, decay_db=12, rng=r)  # 5 抽头，12dB 动态
y = multipath_symbol(tx_waveform, taps, sps)          # 符号间隔卷积
y = carrier_offset(y, cfo_norm=8e-4)                 # 加 CFO
y = awgn(y, snr_for_waveform(snr_db, sps), r)        # 最后加噪声
```

顺序很重要：先过信道、再加噪声（噪声是接收机热噪声，不是信道属性）。

## 面试可能怎么问

- **瑞利 vs 莱斯信道何时用？** 有直视径用莱斯（$K$ 大≈AWGN），全是散射用
  瑞利（$K=0$ 的极限）。深衰落概率：瑞利下 $|h|^2$ 指数分布，$P(|h|^2<t)=1-e^{-t}$。
- **多径为什么会引入 ISI？** 抽头延迟让前一个符号的"拖尾"压到后一个符号
  上 → 符号间干扰。符号率看就是离散卷积。
- **CFO 和相位噪声的区别？** CFO 是确定性线性相位斜坡（频偏）；相位噪声
  是随机游走。两者都让星座旋转，但 CFO 能用两段重复前导一次估掉，相位噪声
  需要逐符号跟踪（模块 06 的 DD 相位跟踪就是干这个的）。
- **为什么抽头功率要归一化？** 把"信道引起的衰落"和"路径损耗"分开——
  本项目研究的是衰落对链路的影响，不归一化则每次实验的 SNR 定义都不一致。
- **什么是频率选择性衰落 vs 平坦衰落？** 信道相干带宽 vs 信号带宽：抽头
  延迟扩展 > 符号周期 → 频选（本项目）；延迟扩展 ≪ 符号周期 → 平坦（单抽头
  复增益）。
