# 03 脉冲成型与匹配滤波

> 代码：`src/phylayer/pulse_shaping.py`
> 验证：`tests/test_pulse_shaping.py`

## 它解决什么问题

矩形脉冲的频谱是 sinc——带宽无穷大，邻道干扰无法接受。必须用一个**带限**的
脉冲 $p(t)$ 把符号"涂"成波形。但带限脉冲会在时间上拖尾，拖尾会砸进相邻符号
——**码间串扰（ISI）**。成型的艺术就是：既要带限，又要在采样瞬间 ISI=0。

## 原理

### 奈奎斯特无 ISI 准则

级联响应 $g(t) = p_{tx}(t) * c(t) * p_{rx}(t)$ 在 AWGN 信道（$c(t)=\delta$）下要满足

$$
g(kT_s) = \begin{cases} 1 & k=0 \\ 0 & k\neq 0 \end{cases}
$$

升余弦（RC）谱正好满足：在 $\pm 1/(2T_s)$ 处滚降对称下降，带宽 $(1+\beta)/(2T_s)$。

### 为什么收发各用一个"根"升余弦

- 总响应要 RC（无 ISI）；
- 接收端又要**匹配滤波**（$h_{rx}=h_{tx}^*(-t)$，最大化采样点信噪比）。

两条件同时满足的唯一解：收发都用 RRC，$|RRC|^2 = RC$。所以发射 RRC → 信道 →
接收 RRC，级联正好是 RC，采样点 ISI=0 且输出 SNR 最优。这就是"根升余弦"名字
的由来，也是真实系统（5G/WCDMA/卫星 DVB）的标准做法。

### 滚降因子 β 的权衡

- $\beta$ 大 → 占用带宽大、拖尾衰减慢 → 对定时误差更鲁棒；
- $\beta$ 小 → 省带宽、但拖尾长 → 定时稍微偏一点 ISI 就暴涨。

工程常用 0.2–0.35（DVB-S2 用 0.35/0.25/0.2）。项目默认 β=0.35, span=11, sps=8。

### 本项目实现

```python
h = rrc_taps(beta=0.35, span=11, sps=8)  # 单位能量
x, h = tx_rrc(symbols, beta, span, sps)  # 上采样(补零) + RRC
y = rx_rrc(channel_output, h)            # 匹配滤波
z = y[len(h)-1 :: sps]                   # 补偿群延迟 len(h)-1, 按符号采样
```

两个要点：
1. **群延迟**：卷积输出要跳过 `len(h)-1` 个样点才对齐符号中心；
2. **SNR 换算**：波形功率 = $E_s$/sps，对波形加噪时目标 SNR 要减 $10\log_{10}(\mathrm{sps})$
   （`channels.snr_for_waveform` 封装了这一步）。

## 验证结果

`test_rrc_cascade_is_nyquist`：收发级联后采样值与原始符号的均方误差 < 1e-4
——数值上证明 ISI 为零。`test_shaped_ber_matches_theory`：整条

## 面试可能怎么问

- **为什么不用矩形脉冲？** 频谱 sinc、旁瓣高、带外辐射大，实际信道带宽受限。
- **升余弦为什么无 ISI？** 频谱关于 $\pm 1/2T_s$ 奇对称滚降 ⟹ 时域在
  $kT_s$ 处过零。
- **为什么收、发各用一个根号？** 总响应要 RC（无 ISI）+ 接收要匹配滤波
  （最大化 SNR），两者同时成立的解就是 RRC/RRC。
- **β 取大取小各有什么好处？** 见上文权衡；追问"为什么 β 小对定时敏感"——
  拖尾衰减慢，采样点偏一点邻居符号的能量漏进来就多。
- **匹配滤波为什么最优？** 在白噪声下最大化采样点 SNR（柯西-施瓦茨可证，
  $h_{opt}=s^*(-t)$）。
- **眼图是什么？** 把波形按 2 个符号周期切片叠画；眼睛张开度 = 定时余量 +
  噪声余量。本项目后续实验页有眼图。
